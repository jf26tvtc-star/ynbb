مشروع روح ينبع - نسخة مطورة (5 جداول + مزايا إضافية)

الجداول الفعلية المستخدمة:
1) categories - فئات الأماكن
2) places - بيانات الأماكن السياحية (+ عمود google_maps_url اختياري)
3) images - صور الأماكن (علاقة واحد إلى متعدد، صورة رئيسية واحدة لكل مكان)
4) users - حسابات المسؤولين
5) messages - رسائل الزوار

للتثبيت الجديد:
1) انسخ المجلد إلى C:\xampp\htdocs\ وسمّه yanbu-tourism.
2) شغّل Apache و MySQL (يفضّل PHP 8.1 فأعلى).
3) من phpMyAdmin استورد database.sql (ملاحظة: هذا يعيد إنشاء جداول المشروع).
4) افتح http://localhost/yanbu-tourism/
5) دخول الأدمن: admin / admin123

النشر على Vercel (الموقع مبني بـ PHP + MySQL، وVercel لا يشغّلهما افتراضيًا):
- vercel.json يشغّل PHP عبر vercel-php، وكل الطلبات تمر على api/index.php الذي يشغّل الصفحة المطلوبة
  ويمنع الوصول لملفات الكود والـ SQL ومجلد includes وأداة admin/diagnose.php.
- على Vercel تُحفظ جلسات تسجيل الدخول والصور المرفوعة داخل قاعدة البيانات (جدولا sessions و image_files)
  لأن ملفات Vercel مؤقتة. محليًا على XAMPP يبقى كل شيء كما هو (ملفات الجلسات ومجلد images).
- حجم الطلب على Vercel محدود بحوالي 4.5MB، فارفع صورًا مجموعها أقل من 4MB في المرة الواحدة.

خطوات التشغيل:
1) أنشئ قاعدة MySQL خارجية مجانية (مثل TiDB Cloud Serverless: https://tidbcloud.com)، ثم من Connect
   انسخ: Host و Port و User و Password، وأنشئ قاعدة باسم yanbu_tourism (أو استخدم الاسم الموجود).
2) في Vercel: Project > Settings > Environment Variables أضف:
   DB_HOST, DB_PORT, DB_USER, DB_PASSWORD, DB_NAME
   (أو DATABASE_URL بصيغة mysql://user:pass@host:port/dbname). يُفعَّل TLS تلقائيًا لأي خادم غير محلي؛
   لخادم يحتاج شهادة خاصة أضف DB_SSL_CA بمسار الشهادة، أو DB_SSL=false لتعطيله.
   وأضف مؤقتًا SETUP_TOKEN برمز سري طويل (12 حرفًا على الأقل).
3) أعد النشر (Deployments > Redeploy)، ثم افتح https://<موقعك>/setup.php وأدخل SETUP_TOKEN
   وكلمة مرور جديدة للمدير. تنشئ الصفحة الجداول والتصنيفات وحساب admin ووجهة مهرجان الزهور، ولا تحذف أي بيانات.
4) احذف SETUP_TOKEN من متغيرات Vercel وأعد النشر لتعطيل صفحة التهيئة، ثم سجّل الدخول من /admin/.

إذا عندك النسخة القديمة ذات 3 جداول وتريد الاحتفاظ ببياناتها:
- خذ Export احتياطي أولاً.
- استورد upgrade_from_3_tables.sql بدل database.sql.

العلاقات:
categories (1) ---- (N) places
places     (1) ---- (N) images
- لا يمكن حذف تصنيف مرتبط بأماكن (RESTRICT). حذف المكان يحذف سجلات صوره (CASCADE).
- users لحسابات الإدارة وmessages لرسائل الزوار؛ لا يحتاجان علاقة مباشرة بالأماكن.

تصحيح توافق قاعدة موجودة مع المشروع (MariaDB 10.4 فأعلى):
- خذ نسخة احتياطية ثم استورد db_upgrade_v3.sql في قاعدة yanbu_tourism.
- يصلح اختلاف sender_name/name في الرسائل، ويضيف هاتف المرسل ورابط خرائط المكان،
  ويوحد قواعد العلاقات دون حذف بيانات أو تغيير كلمة مرور الإدارة.
- لا تستورد database.sql لإصلاح قاعدة قائمة؛ فهو يحذف الجداول ويعيد إنشاءها.
- قد يوجد جدول admin قديم من نسخة سابقة؛ تسجيل الدخول الحالي يعتمد users فقط،
  ولا تحذف الجدول القديم إلا بعد التأكد من عدم الحاجة لبياناته.

ما تمت إضافته/تطويره في هذه النسخة:
- قائمة تنقل موحدة في nav.php: الرئيسية، ينبع البحر، ينبع النخل، ينبع الصناعية، اكتشف الأماكن، خطط رحلتك، من نحن.
- صفحات مناطق ينبع عبر destination.php?area=sea وarea=nakhl وarea=industrial، مع أفكار للزيارة وروابط للبحث عن الأماكن بحسب اسم المنطقة في الاسم أو الوصف أو الموقع.
- صفحة خطط رحلتك (trip.php) لمسارات زيارة مقترحة، وصفحة من نحن (about.php) للتعريف بالموقع والوصول للتواصل والتصنيفات ودخول الإدارة.
- معرض صور تفاعلي متعدد لكل معلم (details.php) مع صور مصغّرة قابلة للنقر.
- رفع عدة صور دفعة واحدة من لوحة التحكم، وتحديد/تغيير الصورة الرئيسية، وحذف أي صورة بمفردها.
- صفحة "التصنيفات" (categories.php) لاستعراض كل فئة مع عدد الأماكن وصورة غلاف، وربطها
  بعرض مخصّص (أيقونة/عنوان) حسب نوعها: بحرية 🏖️ / تاريخية 🏛️ / طبيعية 🏔️ / ترفيهية 🎡.
- إدارة كاملة للتصنيفات من لوحة التحكم (إضافة / تعديل / حذف) مع منع حذف فئة مرتبطة بأماكن.
- رابط خرائط قوقل لكل وجهة (مُدخل يدويًا أو يُولَّد تلقائيًا من اسم المكان وموقعه).
- صورة افتراضية (placeholder) عند عدم وجود صورة بدل رابط صورة مكسور.
- إحصائية عدد التصنيفات في لوحة التحكم.
- واجهة لوحة تحكم عربية متجاوبة بطابع بحري (كحلي عميق + أزرق سماوي)، وقائمة جانبية نصية بدون أيقونات
  مقسّمة لأقسام منسدلة (المحتوى / التواصل / الحساب) تفتح وتُغلق بالضغط على عنوان القسم.
- بطاقات إحصائيات فعلية، وتوزيع الوجهات حسب التصنيف، ومعاينة آخر ثلاث رسائل دون تغيير حالة قراءتها.
- بحث باسم المكان أو الموقع وتصفية حسب التصنيف داخل لوحة التحكم؛ تُعرض أحدث ست نتائج مطابقة.
- مؤشر تغطية الأماكن بالصور وعدد الأماكن التي تحتاج صورًا، مع حالات واضحة عند خلو البيانات.
- تصميم اللوحة معزول في css/admin-dashboard.css ولا يغيّر واجهة الموقع العامة أو يحتاج ترقية لقاعدة البيانات.
- إصلاحات أمان وموثوقية: استعلامات محضّرة (prepared statements) في كل مكان، تحقق من
  صيغة البريد في نموذج التواصل، إصلاح دالة sanitize() التي كانت تُفسد كلمة مرور الأدمن
  وتُسبب ترميزًا مزدوجًا للنصوص عند العرض، إصلاح رابط تسجيل الخروج، وجعل حماية صفحات
  لوحة التحكم تعمل بغض النظر عن اسم مجلد المشروع.

- تصميم ثانٍ (نسخة v3) بهوية "بوابة سياحة وطنية": كحلي عميق + أزرق سماوي (طابع بحر ينبع)، هيرو
  بصورة خلفية كبيرة (تُسحب تلقائيًا من آخر صورة مُضافة) وشريط بحث عائم، شارات تصنيف (pills)
  تحت الهيرو، وأقسام مواضيعية بالصفحة الرئيسية (شرائح أفقية قابلة للتمرير) لكل نوع: بحرية 🏖️ /
  تاريخية 🏛️ / طبيعية 🏔️ / ترفيهية 🎡 — بحيث أول ما تفتح الموقع تشوف كل الخدمات مقسّمة مباشرة
  (مثل أقسام مطاعم/شواطئ/معالم في مواقع السياحة الكبرى)، بدل شبكة واحدة مسطّحة.
- صفحة تفاصيل كل مكان أصبحت ببانر صورة كبير بعنوان فوقه، وقسم "أماكن مشابهة" بالأسفل.
- عمود هاتف اختياري لكل مكان (مفيد لعرض رقم تواصل مطعم/منشأة) — يظهر في صفحة التفاصيل كرابط اتصال.
- خريطة قوقل مضمّنة فعليًا (iframe) داخل صفحة تفاصيل كل مكان (بدون الحاجة لمفتاح API)، بالإضافة
  لزر "فتح في خرائط قوقل" في تبويب جديد.
- أداة تشخيص/إصلاح تسجيل دخول الأدمن: admin/diagnose.php — افتحها من المتصفح إذا واجهت خطأ
  "اسم المستخدم أو كلمة المرور غير صحيحة"، وستفحص قاعدة البيانات وتصلح كلمة المرور بزر واحد
  (يولّد الهاش مباشرة من PHP، فلا يحدث أي تلاعب بالرموز كما يحدث أحيانًا عند لصق SQL يدويًا في
  phpMyAdmin). احذفها بعد التأكد أن كل شيء يعمل.
- db_upgrade_v2.sql: ملف ترقية يضيف الأعمدة الجديدة (google_maps_url، phone) لقاعدة بياناتك
  الحالية دون حذف أي بيانات أدخلتها بنفسك — استخدمه بدل إعادة استيراد database.sql من الصفر.

ملاحظات لمزيد من التطوير (اختياري):
- "التقييم" وقائمة "المميزات" في صفحة التفاصيل حاليًا نصوص ثابتة وليست من قاعدة البيانات.
- يُفضّل إضافة حماية CSRF لنماذج الإضافة/التعديل، وتحديد عدد محاولات تسجيل الدخول.
