روح ينبعلوحة التحكم

تحفظ اللوحة التعديلات مباشرة في مستودع الموقع على GitHub، لذلك تحتاج "مفتاح دخول" من حسابك في GitHub (مرة واحدة لكل جهاز).

كيف أحصل على مفتاح الدخول؟
  1. افتح صفحة إنشاء المفتاح في GitHub (الإعدادات معبّأة مسبقًا).
  2. في Repository access اختر Only select repositories ثم اختر ynbb.
  3. تأكد أن Contents = Read and write، ثم اضغط Generate token.
  4. انسخ المفتاح (يبدأ بـ github_pat_) والصقه هنا.

احتفظ بالمفتاح في مكان آمن ولا تشاركه مع أحد؛ من يملكه يستطيع تعديل الموقع.
