روح ينبعلوحة التحكم

أدخل كلمة مرور لوحة التحكم للمتابعة.

الدخول بمفتاح GitHub (لأول مرة أو إذا نسيت كلمة المرور)

ادخل بالمفتاح مرة واحدة، ثم عيّن كلمة المرور من "الحساب ← كلمة مرور الدخول".

  1. افتح صفحة إنشاء المفتاح في GitHub (الإعدادات معبّأة مسبقًا).
  2. في Repository access اختر Only select repositories ثم اختر ynbb.
  3. تأكد أن Contents = Read and write، ثم اضغط Generate token.
  4. انسخ المفتاح (يبدأ بـ github_pat_) والصقه هنا.

لا تشارك المفتاح مع أحد؛ من يملكه يستطيع تعديل الموقع.
